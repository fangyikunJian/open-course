# 基建与 CS224R 样板 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 CS234 的精读/放映厅工具抽成跨课程共用的 `_kit/`，建起总清单页与跨会话任务清单，然后做出 CS224R L05（PPO）的精读与放映厅样板，交用户确认格式。

**Architecture:** 三层。① `_kit/` 是唯一一份工具（精读生成器 `coursekit` + 放映厅引擎 `theater`），从 `reinforcement learning/` 抽出，**原地保留兼容**；② 每门课一个目录，`course.json` 是讲次元数据的唯一存放处；③ `plan.json` + `build_plan.py` 生成总入口 `★科研学习清单.html`。工具改动一律先加自证（两侧：必须报 / 必须不报），再改实现。

**Tech Stack:** Python 3.12（`pymupdf`、`pypdf` 已装）、Node（`check_reader.js` 零依赖驱动 Chrome CDP）、`yt-dlp` 2026.08.19、`curl`。无需起服务，产出全是双击可开的本地 HTML。

## Global Constraints

- **精读每页 ≥1200 字**（ML 实测基线：用户自制笔记每页约 1814 字，早期精读只有 819 字）。
- **`quote` 覆盖 ≥80%**，分母是有讲解的页（`build_reader.py:QUOTE_COVER_MIN = 0.80`）。
- **表格每 4 页有讲解至少 1 张**（`build_reader.py:TBL_PER_PAGES = 4`）。
- **`quiz` 的键必须是某条 `notes` 的起始页**，否则题永远显示不出来。
- **选项里一律不许出现 `<b>`**（题干 `q`、解析 `why` 里可以）。
- **答案位置必须打散**，固定种子 `20261012`，按文本回写 `a`（不是按下标）。
- **`res.tag` 只许三档**：`已核` / `推断` / `待核`（`build_reader.py:RES_TAGS`）。
- **放映厅单部片镜数 ≤80**（引擎 `go()` 无 try/catch 重放全部前序镜）。
- **图元多样度**：单个整图级图元 ≤25% 有图镜；不同画法 / 有图镜 ≥0.30。
- **画布文字预算**：≤3 个视觉对象 · 单行 ≤20 字 · 合计 ≤80 字。
- **构建脚本不许依赖课程目录之外的文件**（ML 那边因此断过一次构建）。
- **新增或收窄任何检查，必须同时给两侧自证**（PROJECT-SKILL 规矩 E）。
- 所有 Python 脚本顶部保留 `sys.stdout.reconfigure(encoding="utf-8")`，否则 Windows 控制台在第一个中文 `print` 上就抛 `UnicodeEncodeError`。

```python
def check_quiz_leak(quiz):
    """两层泄题都要拦。第一层是加粗（写题时习惯把答案加粗好自己核对，结果印在页上）；
    第二层是位置集中（ML 那边清掉加粗后一查，50 题里 48 题答案在 B，
    闭眼选 B 就满分，等于没修）。"""
    bad, pos, n = [], {}, 0
    for page, items in quiz.items():
        for i, q in enumerate(items):
            for o in q["o"]:
                if "<b>" in o or "</b>" in o:
                    bad.append("第 %s 页第 %d 题：选项里有 <b>" % (page, i + 1))
            pos[q["a"]] = pos.get(q["a"], 0) + 1
            n += 1
    # 位置分布：题数 ≥8 时，任一位置占比超过 50% 即为集中
    if n >= 8:
        for k, v in pos.items():
            if v > n * 0.5:
                bad.append("答案位置集中：%d/%d 题都在第 %d 项"
                           % (v, n, k + 1))
    return bad
```

- [ ] **Step 2: 写 build_plan.py**

`_kit/build_plan.py`。要点：读 `plan.json` → 生成单文件 HTML；配色变量与 `theme.py` 的 `LIGHT` / `DARK` 两套一致；验收标准渲染成 `<input type="checkbox">`，勾选状态存 `localStorage`（键 `plan-check-<n>-<i>`，**带 `plan-` 前缀**，因为 `file://` 下所有本地页共用一个 origin，不加前缀会和各课的自测记录互相覆盖）。

```python
# -*- coding: utf-8 -*-
"""plan.json → ★科研学习清单.html。十个条目各一行，带材料链接与验收勾选。

勾选状态存 localStorage，键带 plan- 前缀 —— file:// 下所有本地页共用一个
origin，不加前缀会和各课精读的自测记录撞键。这个坑 coursekit 的 README 里
已经记过一次。
"""
import io, json, os, sys

sys.stdout.reconfigure(encoding="utf-8")

HERE = os.path.dirname(os.path.abspath(__file__))
ROOT = os.path.dirname(HERE)


def esc(s):
    return (str(s).replace("&", "&amp;").replace("<", "&lt;")
            .replace(">", "&gt;").replace('"', "&quot;"))


def main():
    p = json.load(io.open(os.path.join(ROOT, "plan.json"), encoding="utf-8"))
    rows = []
    for it in p["items"]:
        mats = "".join(
            '<a class="mat" href="%s" target="_blank">%s</a>' % (esc(m["href"]), esc(m["t"]))
            for m in it.get("mats", []))
        checks = "".join(
            '<label class="ck"><input type="checkbox" data-k="plan-check-%d-%d">%s</label>'
            % (it["n"], i, esc(c))
            for i, c in enumerate(it.get("checks", [])))
        rows.append(
            '<section class="item %s"><h2><span class="n">%d</span>%s</h2>'
            '<p class="why">%s</p><p class="meta">%s · %s</p>'
            '<div class="mats">%s</div><div class="checks">%s</div></section>'
            % (esc(it["status"]), it["n"], esc(it["title"]), esc(it["why"]),
               esc(it["tier"]), esc(it["when"]), mats, checks))
    html = TPL.replace("{{TITLE}}", esc(p["title"])) \
              .replace("{{LEDE}}", esc(p["lede"])) \
              .replace("{{ROWS}}", "\n".join(rows))
    out = os.path.join(ROOT, "★科研学习清单.html")
    io.open(out, "w", encoding="utf-8", newline="\n").write(html)
    print("写出 %s（%d 个条目，%d 条验收）"
          % (os.path.basename(out), len(p["items"]),
             sum(len(i.get("checks", [])) for i in p["items"])))


if __name__ == "__main__":
    main()
```

`TPL` 是同文件里的一个三引号字符串，含 `<style>`（两套主题变量 + ☾ 切换按钮）与一段读写 `localStorage` 的脚本。读写必须包在 `try/catch` 里 —— `file://` 下若站点数据被清或处于隐私窗口，`localStorage` 访问会直接抛异常。
