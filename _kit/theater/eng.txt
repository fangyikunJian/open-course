  这是一个可复用的框架。所有引擎代码（放映机、字幕层、总结卡、必答测验、
  SVG 绘图工具箱、字幕防遮挡）都已内置。你只需要改动一个地方：

     ↓↓↓ 最下方 <script> 里 “========= 在这里填内容 =========” 之间的部分 ↓↓↓

  ── 怎么用 ───────────────────────────────────────────────────────────────
  1. 改 CFG：标题、副标题、视频链接（可留空）。
  2. 用 KP / S / SUM / QUIZ 四个函数搭出每个知识点，结构固定：
        KP("知识点名", function(){
          S(时间秒, 画面函数, "讲解段落（可选，按 N 显示）");   // 讲解镜头，可多个
          SUM(时间秒, 知识点号, {h:标题, k:核心结论, m:底层机制, w:常见误解, e:与考试});
          QUIZ(时间秒, 知识点号, {t:题干, o:[选项...], a:正确下标, w:解析});
        });
  3. 画面函数里可用的绘图工具（全部已内置）：
        clearScene()                    清空画布
        setTitle(小标,大标题,副标题)     标题卡
        setBig(大字, 小字)               居中大字（数字/结论）
        setCap(html)                     顶部一句话（支持 <b><i><em><s>）
        setEq("$$...$$", "top")          MathJax 公式（"top" 顶部对齐）
        flip("...<span data-id=x>..")    公式项级变形动画（FLIP）
        T(id, 文本, "hl/res/ded")        flip 用的 token
        note(文本,x,y,"g/y/b/r/v",锚)    画布上的标注
        dots([[x,y]...], "a/b/c", 半径)  散点
        curve(点数组, "fit/fit g/...")    折线/曲线（带描边动画）
        boxNode(x,y,w,h,标签,"g/y/b/r/v") 方块节点
        link(x1,y1,x2,y2)                连线
        matrix({rows,cols,cw,ch,x,y,cell:fn,dim:fn,hl:fn,label,labelCls})  表格/矩阵
        坐标系是 1280×720（16:9），原点左上。
  4. 颜色语义（保持一致，学习者会形成条件反射）：
        蓝 blue = 模型/输入   黄 yellow = 注意力/结论   绿 green = 正确/答案
        珊瑚 coral = 误差/错误   紫 violet = 强调
