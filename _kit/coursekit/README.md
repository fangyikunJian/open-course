# coursekit —— 把一门公开课做成中文精读站

**左边是那一页课件原件，右边是这一页的讲解和自测。一次只出现一页的信息。**
每页配一两道「想一想」，当场判、当场给解释；答过的状态记在本地，换页回来不丢。
科研连接分两层：逐页的贴在卡片末尾，整讲的收在「科研主线」卡里。

整个文件夹是自足的：拷到任何地方都能用，也可以放在所有课程的上一层共用。
脚本只认 `course.json`，不认路径 —— **`course.json` 所在的目录就是课程根目录**。

产出的全是本地文件，双击就能看，不需要起服务。

---

## 一门新课，五步

```bash
# 1. 搭架子（扫课件目录，生成 course.json + 空的内容目录 + 一份样例）
python coursekit/new_course.py "G:/open course/cs231n" --name "CS231n 计算机视觉" --prefix CS231n

# 2. 打开 course.json，把 title / credit 改对
#    （讲题是从 PDF 首页猜的，基本都要手改）

# 3. 照样例写内容：中文精读/data/L01.json

# 4. 生成 + 实测
python coursekit/build_reader.py "G:/open course/cs231n/course.json"
node   coursekit/check_reader.js "G:/open course/cs231n/course.json"

# 5. 生成总入口 index.html
python coursekit/build_hub.py   "G:/open course/cs231n/course.json"
```

在课程目录里跑的话，`course.json` 那个参数可以省掉 —— 脚本会往上找四层。
只建某几讲：`build_reader.py L02 L03`。

## 两个文件

### `course.json` —— 这门课是什么

```jsonc
{
  "id": "cs231n",                 // 存档键前缀，见下面「为什么要前缀」
  "name": "CS231n 计算机视觉",
  "prefix": "CS231n",             // 精读页标题栏上的课程名
  "heading": "…",                 // 总入口的大标题，可以带 HTML
  "lede": "…",                    // 大标题下面那段话
  "credit": "原课件版权归 …",      // 页脚

  "dirs": {
    "slides": "slides",           // 课件在哪
    "reader": "中文精读",          // 精读页生成到哪
    "data":   "中文精读/data"      // 内容文件在哪
  },

  // 总入口上每讲一行，一行里有几个按钮。路径模板里可以用
  // {tag} {pdf} {film} {num_cn} {slides} {reader} {data}
  // 文件不存在、或模板用到了这一讲没有的键，按钮就自动灰掉
  "views": [
    {"key":"reader","label":"精读","color":"#8fb8ff",
     "hint":"左课件右讲解，一次一页，带想一想与科研连接",
     "href":"{reader}/{tag}-精读.html"},
    {"key":"slides","label":"课件","color":"#c79bf0",
     "hint":"原始课件","href":"{slides}/{pdf}"}
  ],

  "lectures": [
    {"tag":"L01",                 // 讲次标识，内容文件名也用它
     "num_cn":"第一讲",            // 不写就从 tag 的数字推
     "title":"图像分类与 k-NN",
     "pdf":"lecture01.pdf",
     "pages":78,                  // 必须和 PDF 实际页数一致
     "video":"https://…",         // 可选，总入口上出现「原讲座 ↗」
     "kp":["…","…"],              // 可选，还没写精读时总入口展开列它
     "more":[{"label":"讲稿全文","href":"transcripts/L01.txt"}]}
  ]
}
```

**讲次元数据只写在这里一处。** 内容文件里不要再存一份，否则早晚对不上。

### `<data>/<tag>.json` —— 这一讲讲什么

```jsonc
{
  // 这一片给自己定的闸门。写了就**永久硬拦**，没写只报数不拦。
  // 加厚是逐片推进的，所以目标也逐片声明 —— 没有全局豁免开关，
  // 也就没有「忘了摘掉」这回事。
  "_目标": {"密度": 400, "quote覆盖": 0.8, "表格每N页": 4},
  // 要守住的数字。写内容前先列，防止为了配合结论把数字改了。
  "_守住的数字": ["γ* ≈ 0.7737 是按教学设定精确求解的", "..."],

  "notes": [
    {"r": [3, 7],                 // 起止页；同一张图的几个阶段算一条
     "t": "标题",
     "star": 2,                   // 0–3，越高越该停下来看
     "quote": "<b>课件这一页的英文原话</b> — <em>强调</em>",  // 渲染在最前面
     "one": "一句话把这页的结论说完",
     "eq": "式子\n第二行",          // 纯文本等宽块，不排版 LaTeX
     "pts": ["要点一", "要点二"],
     "tbl": {"head": ["列一","列二"], "rows": [["a","b"]]},  // 对比/情况/数值表
     "say": "讲稿里说了而课件上没有的话",
     "tip": {"t":"标签","v":"内容","w":1},   // w=1 用醒目底色
     "res": {"tag":"已核", "v":"这一页接上你课题的哪一段", "ref":"简报 §4a"}}
  ],
  "quiz": {
    "3": [{"q":"题面","o":["选项A","选项B","选项C"],"a":1,"why":"解释"}]
  }
}
```

正文里可以用 `<b>` `<code>`，以及两个语义类：
`<span class='k'>` 重点（绿）、`<span class='w'>` 警示（红）。

### 分片

一讲的内容可以写成 `<tag>.a.json`、`<tag>.b.json`… 按页码区间切，构建时合并。
加厚后单讲轻易超过 200 KB，改一处就要整体重写，风险和成本都不对。

**片间页码不许重叠，重号直接报错** —— 静默覆盖会丢掉一整段讲解。
单文件与分片**不许同时存在**，否则会少读一半。两条都有自证：`selftest_shards.py`，必须 4/4。

密度与覆盖率**按片度量**，不按整讲：78 页里厚了 19 页，整讲均值仍然不及格，
于是「这一片做到了」在报告里看不见。分片既是写作单位就该是度量单位。

### 讲级科研主线卡

另开一份 `<tag>.thread.json`，不参与页级合并：

```jsonc
{"title":"…", "arc":"这一讲整体怎么接上课题",
 "pitfalls":[{"v":"…","tag":"已核","ref":"…"}],
 "ammo":    [{"q":"审稿人会问的","a":"预案","tag":"…","ref":"…"}],
 "papers":  [{"t":"标题","id":"arXiv id","why":"与课题的关系"}]}
```

有这份文件，顶栏才出现「科研主线」按钮。
**为什么分两层**：逐页的连接贴着概念走，而「容易踩的坑」「审稿人会问的」
是读完整讲才成立的结论，挂不到某一页上。两种粒度本来就存在，压成一种会丢东西。

## 硬规矩

`build_reader.py` 会挡下这些，挡不住的就会在页面上变成「那道题不见了」：

- **`quiz` 的键必须是某条 `notes` 的起始页。** 挂在中间页上的题永远显示不出来。
- 正确项下标 `a` 必须落在 `o` 的范围内；选项不少于 3 个；**必须给 `why`**。
- `notes` 的页码区间不许重叠，也不许超出该讲的 `pages`。
- 没有讲解的页会被**报出来但不算错** —— 有些页确实只是上一页的增量构建，
  页面会明说「往前翻一页」。但必须报，否则漏写一页和故意留空看起来一模一样。
- **表格的每行格数必须等于表头列数。** 对不上时页面表现为「最后一格空着」，
  不会报错，所以只能机械查。
- **`res.tag` 必须是 `已核` / `推断` / `待核` 之一，`ref` 必须非空，`v` 不许为空。**
  科研格里凡是声称外部事实的话都要能指回出处。把【待核】写成断言是本项目
  明确要防的那类事故 —— 这三条**一律硬拦**，与有没有声明 `_目标` 无关。
- 声明了 `_目标` 的分片，密度 / `quote` 覆盖 / 表格张数达不到就**不出片**。

**`res` 允许整讲为空，这是设计不是遗漏。** 没有诚实连接的讲次就留空 ——
凑出来的连接比没有连接更坏，它会让人以后分不清哪条是真的。
所以科研格**不设数量下限**；设了下限就会逼出凑出来的连接。

内容上的规矩（机器查不了，但同样要紧）：

- **一次只出现一页的信息。** 右栏任何时刻只渲染一张卡片。这是这个格式存在的理由，
  别往一张卡里塞两页的内容。
- **题目对着那一页的课件出**，不是对着知识点泛泛出。
- **题面、选项、解释的字号都不许超过讲解正文。** 字号跳档会「突然放大吓人一跳」，
  `check_reader.js` 会量这一条。
- 数字以课件为准，**一个都不许为了配合结论改**。建议在数据文件开头用注释
  列一份「要守住的数字」清单。

## 页面上的几件事

**存档形状**：`localStorage["<id>-<tag>quiz"]["起始页#题号"] = {a:选了哪一项}`。
纯本地，没有服务端。**只记「答过什么」，不记次数、不记错数、不排名** —— 这套页面是为
理解知识点服务的，不是为考试服务的。换页回来能看见自己上次怎么答的，就够了。

**为什么键要带课程前缀**：`file://` 下所有本地页面共用一个 origin，
两门课都用 `l01quiz` 会互相覆盖。模板里有一段一次性迁移，会把早期
不带前缀的记录搬过来**并删掉旧键** —— 不删的话，用户「清空全部记录」之后
下次打开又被复活一遍。

**已经拿掉的东西（2026-09-29）**：错题本面板、复习模式、「连着答对两次毕业」、
`rw`/`qw` 双计数、错题排序、页条标红、标题告警角标。它们是备考机制，
而这套页面的用途是理解。拿掉时**同一次改动里**删了机制、删了对应的 10 条断言、
补了新断言 —— 删机制不删断言是假红，删断言不补新的是假绿。

**保留的**：每页一两题 · 立即判 · 错项标红同时点亮正解 · 选项锁死 · `why` 解释 ·
「重做」· 答过状态记忆。题目问的是**机制 / 为什么 / 边界**，不是「定义是什么」。

## 踩过的坑

- **内嵌 PDF 换页必须带查询参数**：`PDF + "?p=" + p + "#page=" + p + "&toolbar=0&…"`。
  只改 `#hash` Chrome 不会翻页，而 `frame.src` 读回来却是对的 ——
  要验就验工具栏上的页码，不是 src 字符串。
- **不要用编辑器的预览面板测**：它把页面塞进 `data:` URL，`localStorage` 直接抛
  `SecurityError`，想一想/答过状态/翻页记忆全部测不到。必须起真 `file://` 源，
  `check_reader.js` 就是这么做的。
- **正则穿过 JS 字符串字面量会掉一层反斜杠**：`"\D"` 在字面量里退化成 `"D"`，
  于是「删掉非数字」变成「删掉字母 D」。用字符类 `[^0-9]` 就没这问题。
- **页条上 `.err.on` 的优先级要高于 `.err`**，否则当前页的高亮会被标红盖掉。

## 文件

| 文件 | 干什么 |
|---|---|
| `reader_template.html` | 精读页的引擎：版面、翻页、想一想、科研主线卡。**一份** |
| `build_reader.py` | `course.json` + 内容文件 → 精读页，顺带把能机械查的都查掉 |
| `build_hub.py` | `course.json` → 总入口 `index.html` |
| `check_reader.js` | 起真 Chrome 跑 25 条断言，期望值全从页面自己的数据推出来 |
| `new_course.py` | 扫课件目录搭架子 |
| `_course.py` | `course.json` 的读取与路径解析，前两个脚本共用 |

`check_reader.js` 零依赖（Node 内置的 http / child_process / WebSocket 驱动 CDP），
`new_course.py` 想猜标题和数页数需要 `pymupdf` 或 `pypdf`，没装也能跑，页数填 0 自己改。
