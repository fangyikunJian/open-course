# open course · 强化学习课程中文精读

一套自用的强化学习学习站：**左边挂原始课件 PDF，右边逐页写中文讲解**，配可交互的自测题。
目标不是应试，是**把知识点读透**，并把每一讲接回自己正在做的研究。

> 这里的全部中文内容都是原创笔记。**课件 PDF、字幕、讲稿不在本仓库内**，原因见下。

## 收了哪几门

| 课程 | 内容 | 进度 |
|---|---|---|
| **Stanford CS234**（2019 冬） | 强化学习 | 15 讲全部完成（无 L14，那节是测验） |
| **UW CSE 541**（2025 春） | Interactive Learning（老虎机 / 在线学习 / 实验设计） | 16 份讲义全部结清 |
| **Stanford CS224R**（2025） | Deep RL | 进行中（19 讲） |
| **Sutton & Barto 第二版** | 强化学习导论 | 按节写，只做 CS234 没系统讲过的章节 |

每门课根目录下有 `index.html`（门户）与 `来源.md`（材料从哪来、怎么切的）。

## 精读页长什么样

- **左 PDF / 右讲解**：按页对齐，讲解单元标明它覆盖的页范围。
- **`quote` 格**：幻灯自己的英文原文，逐字抄，不转述。
- **`say` 格**：课堂讲稿里的原话。CS224R 有 19 份完整讲稿，很多关键细节**只在讲稿里、
  幻灯上完全没有**——这一格专门捞那些。
- **`eq` 格**：把公式与推导重排成能一眼看完的纯文本块。
- **科研格 / 讲级主线卡**：把这一讲接回作者自己的课题，并标注证据档位
  （`已核` 逐字核对过 / `推断` 我推的 / `待核` 还没查）。
- **想一想**：每讲十几到几十道自测题，答案位置经过打散（见下面的闸门）。

## 为什么没有课件 PDF

`.gitignore` 挡着 `*/corpus/**/*.pdf`、`*.vtt`、`*.txt`：

1. **体积**——全部材料 400 MB 以上，而本仓库跟踪的内容不到 20 MB。
2. **版权**——课件著作权属于各课作者与学校，本仓库不转载。

各课的 `来源.md` 写明了每份材料的出处与获取方式。**要让左栏的 PDF 显示出来，
需要自己按 `来源.md` 把材料下载到对应的 `corpus/` 目录下。** 不下载也能读右栏的讲解。

## 工具链 `_kit/`

- `build_reader.py` —— 从 `course.json` + 每讲的数据 JSON 生成精读页。
  带一组**硬闸门**：讲解密度、`quote` 覆盖率、表格密度、页范围重叠、
  以及几条防泄题的检查（答案位置是否过度集中、某一项是否从没当过正解、
  选项里有没有残留加粗）。闸门不过就改内容，**不许改目标值让它通过**。
- `check_reader.js` —— 用真实的无头 Chrome 跑 **27 条断言**（主题切换、对比度、
  自测状态持久化、表格渲染、CSS 变量有没有被引用却没定义……）。
- `reshuffle_quiz.py` —— 打散答案位置，**打散完自己验，不合格就换盐重试**。
- `build_hub.py` / `build_portal.py` —— 生成课程门户与总入口。
