1 · 自举：DP 不是「没有偏差」，是没有采样误差

自举 = 不再往下展开，直接用上一轮的估计顶替剩余的一整棵子树。
讲解
先把 DP 的策略评估重画成一棵前瞻树。从当前状态出发，按策略取一个动作，展开一层得到所有可能的后继。 DP 在这里做了两件性质完全不同的事。第一，它把这一层的期望精确算出来——因为 P 已知，求和可以真的做。第二，它不再继续往下展开，而是把每个后继下面整棵剩余的子树换成上一轮的估计 V_{k−1}(s′)。 第二件事就叫自举（bootstrap）。它是这一讲全部比较的支点：接下来的两个算法，一个放弃了第一件事，一个两件都做。

讲解
讲座里有一句很容易记住的话：动态规划不会有偏差，因为你自举的那个 V^π 本来就是 V^π。 听上去无懈可击。但它把两个不同的对象当成了一个。你在第 k 轮自举的不是 V^π，而是 V^π_{k−1}——L2 已经讲清楚了，那是「只剩 k−1 步可走」时的精确值，它不等于无限时域的 V^π。 值得注意的是，她自己在后面填那张对照表的时候又承认了这一点。也就是说这不是一个立场，而是一次口头上的简化，而这个简化恰好落在最容易形成错误模型的地方。

讲解
要把这件事说精确，得先把「偏差」拆成两项，它们的来源完全不同。 第一项是采样误差：你用有限个样本去代替一个期望。DP 没有这一项，因为模型已知，那个对 s′ 的求和是真的做了，一个样本都没用。 第二项是时域截断偏差：你用 V_{k−1} 顶替了剩余的整棵子树，而 V_{k−1} 本身只覆盖了有限步。DP 有这一项。 关键在于第二项会消失，而且消失得很快——由 L2 的 γ-压缩性，误差按 γ^k 几何衰减。所以正确的说法是：DP 没有采样误差；它确实有偏差，但那是一个随 k 几何消失的截断偏差。这比「DP 没有偏差」既更准确，也更有用。

知识点 1 · 总结

DP 没有的是采样误差，不是偏差

核心结论

DP 第 k 轮自举的是 V^π_{k−1}（k−1 步时域的精确值），不是 V^π。两者之差按 γ^k 几何衰减。

底层机制

「偏差」要拆两项：采样误差（用样本代替期望）与截断偏差（用 V_{k−1} 顶替剩余子树）。DP 只有后者。

常见误解

误解：讲座原话「DP 不会有偏差，因为自举的那个 V^π 就是 V^π」—— 差别就在下标 k−1 上。

与你的考试

两者花的钱不同：截断偏差用算力买（多扫几轮，γ^k），采样误差用数据买（N^(−1/2)）。

知识点 1 · 检验

「动态规划的策略评估是无偏的」——这句话的问题在哪？

DP 没有的是采样误差——模型已知，对 s′ 的求和是真的做了。但它每轮顶替进去的 V^π_{k−1} 是「只剩 k−1 步」的精确值，不是无限时域的 V^π，所以存在时域截断偏差，由 γ-压缩性按 γ^k 几何衰减。「完全精确」只在 k→∞ 的极限下成立。「DP 也要采样」是事实错误：DP 遍历所有 s′，一个样本都不抽。「只对确定性策略成立」也不对——随机策略下把 r(s,π(s)) 换成对动作的期望即可，与偏差问题无关。

2 · 采样与自举是两个独立的轴，不是一条滑杆

9 / 69
三个算法的差别，可以完全压进两个是非问题：期望算不算得出来、未来展不展开。
讲解
三个算法的全部差别，可以压进两个是非问题。 第一个：这一层的期望，是算出来的还是抽样抽出来的？DP 算出来（模型已知），MC 和 TD 抽样。 第二个：剩下的未来，是展开到底还是用估计顶替？DP 和 TD 顶替（自举），MC 一路展开到回合终止。 两个问题各有两个答案，所以应该有四个格子。三个算法只填了三个——空出来的那个是「抽样到底、不自举、但也不用模型」……其实那正是 MC；真正空着的是「算期望 + 展开到底」，也就是穷举整棵树，它精确但代价爆炸，所以没人用。

知识点 2 · 总结

采样与自举是两根独立的轴，TD 在对角不在中点

核心结论

DP = 算期望 + 自举；MC = 抽样 + 不自举；TD = 抽样 + 自举。第四格（算期望 + 展开到底）是穷举树，代价指数爆炸。

底层机制

差别全在更新式方括号里的目标：精确一步期望 / 实际回报 G_t / 采样的 r+γV(s′)。

常见误解

误解：「各取一半所以结果在中间」。方差上碰巧成立，收敛目标上不成立（第九集反例）。

与你的考试

最硬的分野：MC 不需要 Markov 性，DP 与 TD 都需要；非 Markov 数据上后两者收敛到错值。

知识点 2 · 检验

下面哪一条差别，不是程度问题而是原理性的？

Markov 性是关于环境的假设，不是算法的一个可调档位：如果状态不是充分统计量，TD 的自举目标 r+γV(s′) 从一开始就不对，再多数据也只会更快地收敛到错的值。而 MC 只平均实际观测到的回报，不依赖这个假设。「方差更低」是典型的程度问题。「在线 vs 等回合结束」与「要不要模型」都是真实且重要的差别，但它们是适用范围的差别：任务是不是回合制、手上有没有模型，都是你事先知道的条件；而 Markov 性坏掉时，算法不会报错，只会安静地给出错误答案。

3 · 首次访问 MC：无偏，而且不需要 Markov 性

16 / 69
Gt=rt+γrt+1+γ2rt+2+⋯+γT−trT
MC = 走完，然后平均。没有模型，没有自举，没有 Bellman 方程。
讲解
蒙特卡洛策略评估朴素到几乎不像一个算法：按策略走完整个回合，算出每个被访问状态的实际折扣回报，然后对多个回合取平均。 没有模型，没有自举，没有 Bellman 方程。它甚至不需要状态是 Markov 的——因为它从不假设「从 s 出发的未来只取决于 s」，它只是把实际发生的回报记下来。 本片用的轨迹是 s₃ → s₂ → s₂ → s₁ → 终止。只有 s₁ 给 +1，γ=1（回合制，有限时域下 γ=1 是安全的——这是 L2 第三集的结论）。所以从 s₃、从 s₂、从 s₁ 出发的回报都等于 1。 注意 s₂ 被访问了两次。这件事下一集会变成一个真正的分歧点。

讲解
这个错误模型在很多场景下是对的：有模型、状态确实 Markov、回合又长，那么 MC 又慢又抖，没理由用它。 但它漏掉了 MC 唯一的、而且是质上而非量上的优势：它是三者里唯一不需要 Markov 性的。 这个优势之所以容易被漏掉，是因为在课堂的表格世界里 Markov 性总是成立的。而在你真正会遇到的问题里——用最近 4 帧当状态的 Atari、把对话历史截断成固定窗口的对话系统、传感器有延迟的机器人——状态几乎从来不是严格 Markov 的。此时 TD 不会报错，它会安静地收敛到一个错的值。

V^π(s)=1N(s)∑i=1N(s)G(i)(s)
首次访问：每回合每状态最多取一个样本，于是样本之间 IID。
讲解
首次访问 MC 的规则只有一句：一个回合里，某个状态只取它第一次出现处的回报，后面再访问到也不算。 这条规则看起来像是在浪费数据，但它换来了一个很硬的性质：每个回合最多给每个状态贡献一个样本，所以这些样本来自不同的回合，彼此独立同分布。 一旦 IID 成立，剩下的全是标准统计：样本均值是无偏的，而且由大数定律相合——样本数趋于无穷时收敛到 V^π。请注意这两条结论没有用到任何强化学习的性质，它们就是「独立同分布样本的均值」这一件事。 下一集会看到，一旦允许同一回合里的多次访问都算数，IID 就破了，无偏性也跟着破了。

知识点 3 · 检验

首次访问 MC 的无偏性，最终依赖于哪一条？

「只取第一次访问」保证了同一个状态的多个回报样本来自不同回合，因而独立同分布；IID 样本的均值是总体均值的无偏估计，这是纯粹的统计事实。Bellman 方程根本没被用到 —— MC 不自举，整条更新式里没有 V(s′)。Markov 性正是 MC 不需要的那一条，这也是它相对 TD 的唯一质上的优势。γ<1在这里也不必要：本集用的就是 γ=1，回合制下有限时域已经保证回报有界（L2 第三集）。

知识点 4 · 检验

为什么「MSE = 偏差 + 方差」这个写法不只是少写了一个上标？

MSE 是一个平方的期望，恒非负；而偏差可以是负的（估计系统性偏低时就是），所以「方差 + 偏差」能算出负数 —— 本集的实测就是 0.808 + (−0.997) = −0.189。一个恒非负的量等于一个可以为负的表达式，这是自相矛盾，不是近似。量纲其实说反了：偏差平方之后才和方差同量纲，这正是那个平方的另一个作用。「方差包含偏差」不对 —— 方差是绕自身均值的离散度，与真值无关，两项是正交的。「只有无偏时等价」恰恰相反：无偏时偏差为 0，0 和 0² 都是 0，两种写法在那时正好等价，所以无偏的情形根本暴露不出这个错误。

知识点 5 · 检验

每次访问 MC 为什么有偏？

首次访问 MC 的无偏性唯一的依据是样本 IID（每回合每状态最多一个样本，样本来自不同回合）。允许同回合多次访问后，这些回报共享后半段的全部随机性 —— 后半段运气好，两个样本会同时偏高，误差叠加而非抵消 —— IID 破了，无偏也就没了。「靠后的回报系统性偏小」不成立：在 Markov 环境里，从 s 出发的回报分布与你第几次到达 s 无关，两次访问的回报各自都是无偏的，坏掉的是它们之间的相关性。Markov 性是 MC 压根不需要的假设。自举更不沾边 —— MC 的更新式里根本没有 V(s′)。

误解：「同一份数据，正确的算法该给同一答案」。数据不回答问题，假设才回答。

与你的考试

谁对是经验问题：状态是不是真的充分统计量。另：离开表格用函数逼近后，无模型方法可能根本不收敛。

知识点 9 · 检验

批量 TD 在 A/B 例上给出 V(A)=0.75，而批量 MC 给出 0。TD 凭什么敢用 0.75？

TD 先用计数估出最大似然 MDP（P(B|A)=1、R(A)=0、R(B)=0.75），再做 DP，于是 V(A)=0+0.75。这一步的实质是跨状态借用数据：A 只被访问一次，但「从 A 出发的未来完全由『在 A』决定」这个 Markov 假设允许它继承 B 的全部八次观测。「样本效率更高」只是结果的描述，不是理由 —— 效率的来源正是那个假设。「TD 无偏而 MC 有偏」把两者说反了：首次访问 MC 无偏，TD 才是有偏的。γ=1与此无关：R(A) 本来就是 0，γ 取什么都不改变这个分歧。若 Markov 性不成立，这个「借用」就是凭空编造，TD 会自信地给出错误答案。

讲解
回头看这九集，承重的是三件事。 第一，采样与自举是两个独立的轴。DP 不采样、自举；MC 采样、不自举；TD 两样都做。TD 不是 MC 与 DP 之间的插值——第九集已经证明，在同一份数据上它收敛到一个和 MC 不同的答案。 第二，无偏不等于更好。MSE 是方差加偏差的平方，TD 每一个有限样本量下都有偏，但方差低得多，所以在数据有限时常常赢。讲座把这个分解口误成了「偏差与方差之和」，而那个式子会给出负的 MSE。 第三，批量 MC 与批量 TD 的分歧不是谁算错了。MC 最小化对观测回报的均方误差，TD 求解最大似然 MDP。哪个对，完全取决于世界是不是真的 Markov——而这是一个关于环境的经验问题，不是一个关于算法的数学问题。 下一讲从评估转到控制。一旦要改进策略而不只是评估它，V 就不够用了——你需要 Q，而要估 Q 就必须访问那些当前策略不会选的动作，于是探索成为不可回避的问题。
