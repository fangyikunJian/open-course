这一讲做两件事：把老虎机讲完，然后把整套搬回 MDP。 前半讲从频率派换到贝叶斯派。L11 的 UCB 是频率派的：用 Hoeffding 造一个置信区间，然后对区间的上端乐观。贝叶斯派换一套语言——维护一个后验分布，用共轭性让更新有闭式，然后……然后怎么办？ 答案是 Thompson 采样，而它简单到有点不像话：从后验里抽一组参数，假装它就是真的，按它贪心，观察，更新。四步，没有置信区间，没有奖励加成。而它恰好实现了一个叫「概率匹配」的理想规则——不是近似，是按定义相等。 中间插一个换判据：PAC。遗憾是把所有错加起来，于是「很多人头疼」和「几个人严重副作用」是一样的。PAC 换成数大错的个数。在病人身上，这个区别不是技术性的。 后半讲回到 MDP，而结论比预期难看：乐观初始化本身没有任何保证。Even-Dar 与 Mansour 证出的 PAC 结果需要的初始值里含一个 10^T 量级的因子。真正能用的是基于模型的 MBIE-EB：用计数拟合模型，加一个 β/√N(s,a) 的奖励加成，再规划——它的样本复杂度是 |S|、|A|、1/(1−γ)、1/ε、1/δ 的多项式。 这一讲的转录稿有多处问题，最要紧的一处是根号被系统性地丢掉——UCB 的奖励项、MBIE-EB 的常数都中招。本片逐处标出。

1 · 依赖差距的界：算法不需要知道差距，遗憾却由差距决定

2 / 65
Regret(T)=O(∑a:Δa>0log⁡TΔa)
L11 证的是不依赖差距的 √T 界。UCB 还有一个界，长得完全不同。
讲解
L11 花了四集证出 UCB 的遗憾是 O(√(mT log(T²/δ)))。那条界有一个重要性质：它完全不涉及差距，对任何一组臂一致成立。 但同一个算法还有另一条界，形状完全不同：遗憾是 Σ log T / Δ_a 量级——对数增长，而系数由各个臂的差距决定。 两条界描述的是同一个算法。这一集说清它们的分工，以及第二条界告诉了我们什么第一条说不出来的东西。
3 / 65
算法得先知道差距界里有 Δ，算法总得算它吧
算法从头到尾不碰 Δ。它只是被 Δ 支配，而不是使用 Δ。
讲解
这是读到这类界时最容易犯的错：界里出现 Δ_a，就以为算法需要知道它。 不需要。把 UCB 的规则翻出来看——拉 Q̂ + √(2 log t / N_t(a)) 最大的臂。里面只有经验均值和计数，没有 Δ，也没有任何需要事先知道的问题参数。 差距出现在界里，不在算法里。 这个区分有个名字：依赖问题的界（problem-dependent bound）。它说的是「同一个算法，在不同的问题上表现不同，而不同的程度由问题的这个量决定」。 这类界在 RL 里很常见，而把它误读成「算法需要这个量」会得出完全错误的结论——比如以为这个算法没法用。

知识点 1 · 总结

依赖差距的界：算法不用知道 Δ，遗憾却由 Δ 决定

核心结论

Regret = O(Σ_{Δ_a>0} log T / Δ_a)。UCB 的规则里只有经验均值和计数 —— 没有 Δ。界在描述算法，不在规定算法。

底层机制

断脚趾实例（0.95/0.90/0.10）：1/Δ = 20.000 与 1.176，占比 94.4% 对 5.6%。难的是区分 0.95 和 0.90，不是避开 0.10。

常见误解

误解：「界里有 Δ，算法总得先算它」。误读成这样会得出「这算法没法用」的错误结论。

与你的考试

两条界分工不同：不依赖差距（√T，对所有问题一致，但松）；依赖差距（log T，形状更好，但 Δ→0 时系数爆炸）。两条都对。

知识点 1 · 检验

在断脚趾实例（0.95 / 0.90 / 0.10）里，依赖差距的界主要由哪个臂贡献？

界是 Σ log T / Δ_a，差距在分母上：Δ=0.05 给出 1/Δ = 20.000，Δ=0.85 只给出 1.176，占比 94.4% 对 5.6%。那个明显糟糕的臂几次采样就能排除，几乎不贡献难度；难度几乎全部来自区分两个都不错的选项。这与 L11 的 Lai–Robbins 下界形状一致（那里是 Δ/KL，同样随差距变小而增大）。「各一半」差了 17 倍。「最优臂」它的 Δ=0，根本不在求和里。

讲解
这一集把断脚趾实例真的跑几步。 先把式子写对，因为这一讲的转录稿有一个系统性的问题：根号被反复丢掉。 正确的是：U_t(a) = Q̂_t(a) + √( 2 log t / N_t(a) )——根号盖住整个分式，计数在根号里面。 转录稿里出现过「plus the square root of 2 log t」然后计数被甩到根号外面，也出现过「UCB of a3 is gonna be equal to 2 log 3 divided by 1」完全没有根号。 这一处不像别的笔误那样无害——丢了根号数值就整个错了。下面几个数全靠它。 另外注意这里的常数是 2（√(2 log t / N)），这是 Auer 等人的写法。Sutton & Barto 写成 c·√(ln t / N)，c 是可调的。两者不是一回事，别混着引。

这个错误模型来自 ε-贪心留下的印象：探索 = 给每个动作一点随机概率。 但定向的探索不长这样。UCB 在把注意力分给「看起来还有可能最好」的臂的同时，给那些已经明显没戏的臂的概率是恰好零——不是很小，是零。 讲座原话：「while UCB is still splitting its attention among all the arms that look good, it's not putting any weight right now on the arms that it doesn't think could be good」。 下面两镜把这个「零」算出来。

讲解
看什么：前两根一样高，第三根明显矮一截 —— 矮的正好是 1.0，也就是经验均值的差。三个臂的奖励项完全相同（都只拉过一次），所以此刻上置信界的排序就是经验均值的排序。　—— 开局各拉一次，假设得到 1、1、0（讲座设定的情形）。此时 t=3，每个臂 N=1。 奖励项对三个臂完全相同：√(2 log 3 / 1) = 1.4823。 于是： 手术：1.0 + 1.4823 = 2.4823 并指固定：1.0 + 1.4823 = 2.4823 不处理：0.0 + 1.4823 = 1.4823 前两个打平——讲座说这时随机破平，各 50%。第三个差了整整 1.0，不可能被选中。 注意此刻算法还不知道不处理的真实成功率是 0.10；它只看到一个 0。但这已经足够把它排到 argmax 之外了。

知识点 2 · 总结

UCB 给明显坏的臂恰好零概率；ε-贪心给它 0.0333

核心结论

开局各拉一次得 1,1,0，t=3：奖励项对三臂相同 √(2 log 3/1)=1.4823，于是上界 2.4823 / 2.4823 / 1.4823。第三个进不了 argmax。

3 · 为什么必须上界：用下界贪心会确认偏误锁死

16 / 65
既然「加上半径」这么管用，减去它会怎样？
讲解
一个很自然的问题：既然「均值加半径」这么管用，那「均值减半径」呢？ 下置信界也是一个完全合理的量——它是「这个臂至少有多好」的保守估计。选下界最高的臂，听起来像是一个稳健的规则：只选那些你有把握不差的。 讲座在这里停下来让大家讨论了几分钟，因为这个问题的答案正是乐观之所以必要的理由。 这一集算这个答案。
17 / 65
用下界更稳健只选有把握不差的，保守一点总没错
结果正相反：用下界会确认偏误锁死，遗憾变成线性。
讲解
这个错误模型在很多场合是对的——在已经部署的系统里做决策，保守通常是美德。 但在需要学习的场合，它会自毁。 讲座给的设定是两个臂：a1 的上界更高，a2 的下界更高。按下界规则，你会一直选 a2。 课上一个学生说出了关键词：confirmation bias，确认偏误。 下一镜把这个机制拆开，它比「保守」这个词能解释的要精确得多。

没被拉的臂：n 冻住，而 log t 在涨 —— 它的半径越来越宽。
讲解
看什么：柱子一路变高：一个从没再被拉过的臂（n 冻在 1），它的半径 √(2 log t) 随时间持续增长 —— 2.146 到 4.799。这一个事实同时解释了 UCB 为什么必然回头，和 LCB 为什么永不回头。　—— 机制的核心是一个很小的观察：没被拉的臂，它的半径会随时间变宽。 因为半径是 √(2 log t / n)：n 冻住不动，而 t 一直在涨。实测这个半径： t=10 → 2.1460 t=10² → 3.0349 t=10³ → 3.7169 t=10⁴ → 4.2919 t=10⁵ → 4.7985 现在把这一个事实分别代进两条规则： 上界规则：这个臂的分数是「均值 + 半径」，半径变宽 ⟹ 分数上升 ⟹ 迟早会被选中。 下界规则：分数是「均值 − 半径」，半径变宽 ⟹ 分数下降 ⟹ 越不拉越不会拉。 同一个量，符号一翻，行为完全相反。一个保证回头，一个保证不回头。

讲解
看什么：四根柱子一根比一根高，最后停在 30.0。这是「线性遗憾」最直白的样子 —— 每步的损失非但不降，还涨了（早期还有些运行没定下来，定下来之后就再也不动了）。对照 UCB 同期：24.64 → 2.07。　—— 实测。两个臂 (0.55, 0.45)——讲座说两臂情形最容易想清楚，也确实最能看出问题。每个数据点 300 次独立重复。 下界规则的每千步遗憾： T=10³ → 25.05 T=5×10³ → 26.34 T=2×10⁴ → 28.34 T=8×10⁴ → 30.00 不降反升，最后停在 30.0。同期 UCB：24.64 → 12.71 → 5.68 → 2.07，一路下降。 把锁死的比例拆出来看，机制就完全显形了：30.0% 的运行最终锁死在次优臂上，而且这个比例不随 T 衰减（25.0% → 26.3% → 28.3% → 30.0%，在往上走）。 而锁死那部分的每千步遗憾是 99.999——精确等于 1000 × Δ = 1000 × 0.10 = 100。完全锁死，每一步都在亏满额，永远不回头。 0.30 × 100 = 30.0，正好对上总数。线性遗憾就是这么来的。

37 / 65

讲解
解法叫 Thompson 采样，整个算法四步： 一、从每个臂的后验里抽一个参数。 二、假装抽到的就是真的。 三、按这组假想的真值贪心，取 argmax。 四、观察奖励，更新那个臂的后验。 没有置信区间，没有奖励加成，没有 δ，没有积分。 第二步是最反直觉的：为什么可以把一个随机抽样当成真的去贪心？这一集就是回答它。

讲解
最自然的解读是：那个积分算不了，就用蒙特卡洛估一估——多抽几组样本，数一数每个臂当最大值的频率，得到概率的估计，然后按这个估计去随机选臂。 这不是 Thompson 采样在做的事。 Thompson 采样只抽一次，而且根本不去估那个概率。它抽一组 θ，取 argmax，选那个臂，完事。 而它得到的选择分布，恰好等于概率匹配要的那个分布。不是估计，不是近似——相等。 下一镜说明为什么，以及数值上验一遍。

知识点 9 · 总结

MBIE-EB：计数建模 + β/√N 奖励加成，样本复杂度是多项式

核心结论

四步：数 N(s,a) → MLE 拟合模型 → 奖励加 β/√N(s,a) → 当成真的去规划。乐观没消失，它从值的初始化搬到了奖励函数里，衰减率仍是 1/√N。

底层机制

β = (1/(1−γ))·√( ½·ln(2|S||A|m/δ) )。三块各有来历：1/(1−γ) 是有效时域，log 里的 |S||A| 是并集界（同 L11 第八集），½ 与根号来自 Hoeffding 反解（同 L11 第六集）。

常见误解

误解：「无模型更简单所以更好」。在探索的理论上反过来 —— 模型把「我对这里了解多少」显式记下来了，而 Q 值里看不出哪部分来自侥幸。

知识点 9 · 检验

MBIE-EB 的样本复杂度是哪些量的多项式？

讲座把它说成「多项式于 γ」，但真正的依赖是 1/(1−γ)（有效时域），以及 1/ε、1/δ。这个区别关键：γ 永远在 [0,1) 里有界，而 1/(1−γ) 在 γ→1 时爆炸 —— γ=0.9 是 10，γ=0.99 是 100，γ=0.999 是 1000。说成「多项式于 γ」会让人以为长时域是免费的。「指数」那是上一集 Even-Dar & Mansour 的 10^T，正是 MBIE-EB 要对照的反面。「与 γ 无关」β 里第一个因子就是 1/(1−γ)。
